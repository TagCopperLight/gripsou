# Categorization

{% hint style="warning" %}
This feature is not activated by default on your domain. Please contact us to request access.&#x20;
{% endhint %}

Upon activation, the property `categories` is available in the [Bank transactions](/api-reference/products/data-aggregation/bank-transactions.md) or in the  [`ACCOUNT_CATEGORIZED`](/api-reference/products/data-aggregation/bank-accounts.md#account-categorized) webhook.&#x20;

## List bank transactions categories&#x20;

<mark style="color:blue;">`GET`</mark> `https://{domain}.biapi.pro/2.0/users/{userId}/transactions?expand=categories`

List bank transactions with their associated categories of the Authenticated User. By default, only active (non-deleted) transactions are returned; use the `all` parameter to retrieve the complete list.
